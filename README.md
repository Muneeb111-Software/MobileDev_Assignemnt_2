# Campus Lost and Found App

## Overview
Campus Lost and Found is a Flutter application that helps students browse lost and found items on campus. Students can view item names, locations, statuses, and additional details.

## Features
- Displays 8 campus lost and found items.
- Shows each item's name, location, and status.
- Uses `ListView.builder` to display items.
- Includes a Details button for each item.
- Navigates to a separate screen to view item details.

## Technologies Used
- Flutter
- Dart
- Material Design widgets

## Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio or VS Code.
3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Project Structure

- `main.dart` — Contains the item list, home screen, and item details screen.

## Purpose
This project was developed as a Flutter learning assignment to practice list building, UI design, and navigation between screens.
